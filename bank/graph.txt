A: symmetric with zero diagonal
B: upper triangular

ANS: A

Q: Which graph is bipartite?
A: $K_3$
B: $C_5$
C: $C_6$
D: $K_4$
ANS: C

S: shortest-paths
Q: Which algorithm finds single-source shortest paths when some edge weights are negative (but there is no negative cycle)?
A: Dijkstra
B: Bellman–Ford
C: Prim
D: BFS
ANS: B

S: spectral

A: $0$
B: $1$
C: $3$
D: depends on the number of edges
ANS: C
EXP: $x^TLx=\sum_{(i,j)\in E}(x_i-x_j)^2=0$ exactly when $x$ is constant on each component.
That gives one independent null vector per component, so the multiplicity is 3. Spectral clustering uses this fact.

@ graph h graph-h-010
T: Spectrum of the normalised adjacency
S: spectral
Q: In graph neural networks, $\hat A=D^{-1/2}AD^{-1/2}$ (graph with no isolated vertices). Its eigenvalues always lie in:
A: $[-1,\ 1]$
B: $[0,\ 1]$
C: $[0,\ 2]$
D: $[-d_{max},\ d_{max}]$
ANS: A
EXP: $\hat A=I-L_{sym}$, and the normalised Laplacian $L_{sym}$ has eigenvalues in $[0,2]$, so $\hat A$'s lie in $[-1,1]$.
