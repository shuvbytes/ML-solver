@ stat e stat-e-034

@ stat e stat-e-045
T: When MAP equals MLE
S: bayesian-inference
Q: For which prior is the MAP estimate of $\theta$ always the same as the MLE (assuming the MLE lies inside the prior's support)?
A: A normal prior centred at the MLE
B: Any conjugate prior
C: A Laplace prior centred at zero
D: A uniform (flat) prior on the parameter space
ANS: D
EXP: $\hat\theta_{MAP}=\arg\max_\theta\,[\log p(x\mid\theta)+\log p(\theta)]$. If $p(\theta)$ is constant, the second term does not change the maximiser, so MAP $=$ MLE.
A Laplace prior at zero adds an $L_1$ penalty (lasso), and a normal prior adds an $L_2$ penalty (ridge). Both pull the estimate away from the MLE. Conjugacy only makes the posterior easy to compute, it does not remove the prior's effect.

@ stat e stat-e-046
T: Conjugate prior for a Poisson rate
S: bayesian-inference
Q: Counts $x_1,\dots,x_n$ are i.i.d. Poisson$(\lambda)$. Which prior family on $\lambda$ is conjugate, so that the posterior is in the same family?
A: Beta
B: Gamma
C: Normal
D: Dirichlet
ANS: B
EXP: The Poisson likelihood is $\propto \lambda^{\sum x_i}e^{-n\lambda}$. A Gamma$(\alpha,\beta)$ prior (rate $\beta$) has density $\propto \lambda^{\alpha-1}e^{-\beta\lambda}$.

[[D]] True: the log-likelihood grows like $n$ while the log-prior stays fixed, so the prior's influence vanishes.

S: bayesian-inference
Q: With a uniform $\text{Beta}(1,1)$ prior on $\theta$, you observe $2$ successes in $2$ trials, so the posterior is $\text{Beta}(3,1)$ with density $3\theta^2$ on $[0,1]$. What is the Bayes estimate of $\theta$ under absolute-error loss $|\theta-\hat\theta|$?

C: $0.794$

T: Posterior predictive variance in a Normal model
S: bayesian-inference
Q: Let $X\mid\mu\sim N(\mu,1)$ with prior $\mu\sim N(0,1)$ (second parameter is the variance). After observing one value $x=2$, what is the variance of the posterior predictive distribution of a new observation $X_{\text{new}}$?

B: $1$
C: $2$
D: $1.5$
ANS: D
EXP: Posterior: precision $1+1=2$, so $\mu\mid x\sim N(1,\,0.5)$.

@ stat h stat-h-071
T: Maximum likelihood as KL minimisation
S: information-theory
Q: Let $\hat P$ be the empirical distribution of a training set and $Q_\theta$ a model. Minimising the average negative log-likelihood $-\frac1n\sum_i\log Q_\theta(x_i)$ over $\theta$ is equivalent to minimising which quantity?
A: $D_{KL}(\hat P\,\|\,Q_\theta)$
B: $D_{KL}(Q_\theta\,\|\,\hat P)$
C: The entropy $H(Q_\theta)$
D: The entropy $H(\hat P)$
ANS: A
EXP: The average NLL is the cross-entropy $H(\hat P,Q_\theta)=-\sum_x\hat P(x)\log Q_\theta(x)$.
$H(\hat P,Q_\theta)=H(\hat P)+D_{KL}(\hat P\|Q_\theta)$, and $H(\hat P)$ does not depend on $\theta$. So the MLE minimises the forward KL $D_{KL}(\hat P\|Q_\theta)$.
The reverse KL $D_{KL}(Q_\theta\|\hat P)$ is what variational inference minimises. It is infinite whenever $Q_\theta$ puts mass off the training points, so it is not equivalent to the MLE.

T: Best prediction under noisy labels
S: information-theory
Q: For a certain input, the true label is $1$ with probability $0.8$ and $0$ with probability $0.2$. A model predicts $P(y=1)=q$. Which $q$ minimises the expected cross-entropy loss, and what is the minimum expected loss in bits?
A: $q=1$, loss $0$ bits
B: $q=0.8$, loss $0$ bits
C: $q=0.5$, loss $1$ bit
D: $q=0.8$, loss about $0.722$ bits
ANS: D
EXP: Expected loss: $L(q)=-0.8\log_2q-0.2\log_2(1-q)=H(p)+D_{KL}(p\|q)$, which is minimised at $q=p=0.8$ (KL $=0$).
The minimum is the entropy $H(0.8)=-0.8\log_2 0.8-0.2\log_2 0.2\approx0.722$ bits, the noise that no model can remove.
$q=1$ looks confident but gives infinite loss on the 20% of cases with label $0$. Cross-entropy rewards calibrated probabilities, not just the right argmax.

@ stat h stat-h-073
T: Mutual information with zero correlation
S: information-theory
Q: $X$ is uniform on $\{-1,0,1\}$ and $Y=X^2$. Then $\text{Cov}(X,Y)=0$. Using base-2 logarithms, what is $I(X;Y)$?
A: $0$ bits
B: about $0.918$ bits
C: about $1.585$ bits
D: about $0.667$ bits
ANS: B
EXP: $Y$ is a function of $X$, so $H(Y\mid X)=0$ and $I(X;Y)=H(Y)$.
$Y=0$ with probability $\frac13$ and $Y=1$ with probability $\frac23$: $H(Y)=\frac13\log_23+\frac23\log_2\frac32\approx0.918$ bits.
$0$ is the trap: zero correlation only rules out a linear relation, while $I(X;Y)=0$ if and only if the variables are independent. $1.585=\log_23$ is $H(X)$, which would apply only if $Y$ determined $X$.

@ stat h stat-h-074
T: Jensen–Shannon divergence of disjoint distributions
S: information-theory
Q: Let $P=(1,0)$ and $Q=(0,1)$ on two outcomes. Using base-2 logarithms, what is the Jensen–Shannon divergence $\text{JS}(P,Q)=\frac12D_{KL}(P\|M)+\frac12D_{KL}(Q\|M)$, where $M=\frac12(P+Q)$?
A: $+\infty$
B: $0$
C: $2$ bits
D: $1$ bit
ANS: D

@ stat h stat-h-075
T: Information one coin gives about a sum
S: information-theory
TYPE: nat
TOL: 0.01
Q: $X$ and $Y$ are independent fair coins taking values $0$ or $1$, and $S=X+Y$. Using base-2 logarithms, what is $I(X;S)$ in bits? Enter the number.
ANS: 0.5
EXP: $I(X;S)=H(S)-H(S\mid X)$.
$S\in\{0,1,2\}$ with probabilities $\frac14,\frac12,\frac14$: $H(S)=\frac14(2)+\frac12(1)+\frac14(2)=1.5$ bits.
Given $X$, $S=X+Y$ is still a fair coin flip (shifted by $X$), so $H(S\mid X)=H(Y)=1$ bit.
$I(X;S)=1.5-1=0.5$ bits. Knowing $X$ removes half a bit of the uncertainty about $S$.
